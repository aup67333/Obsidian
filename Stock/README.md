# Stock

這是一個 Obsidian 儲存庫，用來整理與追蹤股票相關消息。

主要用途包含：

- 記錄每日市場焦點與重要新聞
- 整理台股、產業、個股與總體經濟相關資訊
- 保留投資觀察、事件脈絡與後續追蹤線索
- 建立可回顧、可搜尋的股票研究筆記

## 目前結構

```text
2026/
  台股/
    今日焦點.md
```

資料夾可依年份、市場或主題分類，例如：

- `2026/台股/`
- `2026/美股/`
- `2026/產業/`
- `2026/個股/`
- `2026/總經/`

## 建議記錄格式

每則消息可包含以下欄位，方便日後搜尋與回顧：

```markdown
## 標題

- 日期：
- 市場：
- 股票代號：
- 來源：
- 重點摘要：
- 可能影響：
- 後續觀察：
```

## 使用原則

這個儲存庫重點在於累積可追蹤的投資資訊，而不是即時交易指令。筆記應盡量保留消息來源、事件背景與自己的判斷依據，方便之後回頭驗證。
